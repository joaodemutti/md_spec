# vscode_spec

Setup pessoal de VS Code e Claude Code no Windows: o que instalar, as configurações, os atalhos e as travas do
Claude. Tudo genérico: o que é de um projeto aparece como `<placeholder>` e é trocado na instalação.

| Arquivo | O que tem |
| --- | --- |
| `setup-vscode.md` | extensões, `settings.json`, `keybindings.json`, preview e PDF de markdown |
| `atalhos.md` | os atalhos pessoais, os padrões úteis do VS Code e os do Claude Code (extensão, terminal e app) |
| `claude-code.md` | configurações do Claude Code, as travas (commit/push, merge, rodapé de IA) e as regras globais |
| `cli-remote-session/` | sessão Remote Control que sobe no logon (tarefa agendada) e os comandos `/claude`, `/c`, `/p`, `/!` e `/my-sessions` |
| `pdf-checkboxes.md`, `pdf_todo/` | PDF com checkbox clicável |
| `vscode/`, `claude-code/` | os arquivos prontos para copiar |

## Máquina nova, nesta ordem

1. VS Code: `setup-vscode.md` (extensões, Chromium, `settings.json`, `keybindings.json`, segurança do preview).
2. Claude Code: `claude-code.md` (travas, `CLAUDE.md`, `settings.json`).
3. Remote Control no logon e conversa entre sessões, se for usar: `cli-remote-session/README.md`.
